# DRISHTI — Prototype Results

This folder contains representative outputs generated by the current **DRISHTI** prototype.

The results demonstrate the different stages of the proposed diabetic retinopathy screening workflow, including image enhancement, evidence visualization, and automated reporting.

---

## Output Files

### `enhanced_fundus.png`

Enhanced retinal fundus image produced during the preprocessing stage.

The enhancement stage is intended to improve the visibility of retinal structures and image features before screening and evidence analysis.

---

### `explainability_map.png`

Prototype evidence visualization generated from the retinal image.

The current implementation demonstrates evidence regions using image-processing-based visualizations such as:

* Bright-region evidence
* Dark-region evidence
* Local-variation evidence

These visualizations demonstrate the explainability concept and should not be interpreted as clinically validated lesion localization.

---

### `lesion_reference.png`

Reference visualization used to demonstrate retinal lesion/evidence regions within the prototype workflow.

This is a prototype visualization and is not a clinically validated lesion segmentation result.

---

### `DRISHTI_Report.txt`

Automatically generated screening report containing information such as:

* Demo/Patient ID
* Image quality
* DR grade
* Classification
* Confidence
* Evidence summary
* Recommendation
* Timestamp

The report is intended to demonstrate how screening information could be organized for a future decision-support workflow.

## Image Quality Rejection Example

The prototype also includes a deliberately blurred test image to demonstrate the quality-gate rejection workflow.

Example behaviour:

```text
Input Image
     ↓
Quality Assessment
     ↓
Poor Focus Detected
     ↓
REJECTED
     ↓
Refocus and Recapture
```

This demonstrates the intended principle of preventing low-quality retinal images from proceeding directly to the screening stage.

---

## Important Interpretation

The current results are intended for:

* Academic demonstration
* Prototype evaluation
* SIH 2026 screening
* Research and development
* Workflow visualization

They should **not** be interpreted as:

* Clinical diagnostic results
* Clinically validated AI predictions
* Medical advice
* Certified medical-device output
* Measured clinical sensitivity or specificity

The current prototype uses a subset of **100 PNG retinal images from the APTOS 2019 dataset**.

Broader evaluation using datasets such as **DRIVE, IDRiD, and MESSIDOR-2** is planned for future development and is not claimed as completed evaluation in the current prototype.
